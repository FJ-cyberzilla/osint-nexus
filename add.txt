Implementation Breakdown
​1. Core Detector Component
​Path: osint_nexus/core/detectors/webrtc.py
​Implement the WebRTCDetector extending BaseDetector. It evaluates JS payload payloads (STUN candidate IPs vs HTTP request IPs) to detect proxy bypasses and headless environments.



"""WebRTC network leak and anti-bot detector."""

from __future__ import annotations

from typing import Any
from osint_nexus.core.detectors.base import BaseDetector

class WebRTCDetector(BaseDetector):
    """Detects proxy/VPN bypasses via WebRTC ICE candidate leaks."""

    def analyze(
        self, 
        request_ip: str, 
        webrtc_payload: dict[str, Any]
    ) -> dict[str, Any]:
        public_ips = webrtc_payload.get("publicIPs", [])
        is_headless = webrtc_payload.get("isSpoofedOrHeadless", False)

        # Flag risk if WebRTC public IP does not match current socket TCP IP
        ip_mismatch = any(ip != request_ip for ip in public_ips)

        return {
            "has_webrtc_leak": ip_mismatch,
            "detected_public_ips": public_ips,
            "local_ips": webrtc_payload.get("localIPs", []),
            "mdns_hostnames": webrtc_payload.get("mDNSHostnames", []),
            "is_headless_or_spoofed": is_headless,
            "risk_score_delta": 0.45 if ip_mismatch or is_headless else 0.0,
        }

3. Passive Telemetry Probe
​Path: osint_nexus/core/telemetry/probes/webrtc_leak.py
​Place browser script injection and passive STUN gathering alongside dns_leak.py and hardware_telemetry.py.


"""WebRTC active probe for browser automation pools."""

from osint_nexus.core.telemetry.base import BaseProbe

class WebRTCLeakProbe(BaseProbe):
    """Executes JS script in browser pool engines to harvest ICE candidates."""
    
    async def run_probe(self, page_context: Any) -> dict[str, Any]:
        # Inject WebRTC JS snippet into headless browser (Playwright/PyQt)
        return await page_context.evaluate("() => new WebRTCFingerprintDetector().analyze()")


Wiring into the System Architecture
​Detection Flow: BrowserPoolManager \rightarrow WebRTCLeakProbe \rightarrow WebRTCDetector \rightarrow DetectionEngine \rightarrow FingerprintAgent.
​Database Storage: Store candidate outputs in osint_nexus/core/db/fingerprint_repository.py to retain history across scans.
