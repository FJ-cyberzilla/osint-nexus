Engineering Highlights

Advanced Capabilities & Technical Specifications

Intelligent Recon & Entropy

Passive fingerprinting analyzes entropy signatures across HTTP headers, TLS handshakes, TCP options, and NTP timestamps to evade honeypots and rate-limiting.

Asynchronous Persistence

Powered by `aiosqlite` with FTS5 full-text search index support, fast caching layers, and bulk batch result dumping for large-scale OSINT audits.

Android & Termux Optimized

Fully configured for high-performance mobile execution environments via Termux with automatic fallback modes and secure environment variable handling.

Secure Credential TUI Modal

Interactive `.env` credential management prevents accidental API key leaks in version control while providing graceful degradation if keys are missing.
