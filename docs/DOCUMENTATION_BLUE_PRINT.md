# OSINT-Nexus Documentation Blueprint

This document outlines the architectural standards and documentation structure for `osint-nexus`, ensuring complete alignment between the codebase and documentation.

## Documentation Scope
1. **User Guide** (`docs/USERGUIDE.md`): Installation, Go build steps, configuration, and operational workflows.
2. **CLI & TUI Reference** (`docs/CLI_COMMANDS.md`, `docs/TUI_COMMAND_CENTER.md`): Command flags and Bubble Tea TUI dashboard interaction.
3. **Type System** (`docs/TYPE_SYSTEM.md`): Statically typed domain models and interfaces in Go.
4. **Project Structure** (`docs/STRUCTURE.mmd`): Mermaid diagrams illustrating package relationships.
