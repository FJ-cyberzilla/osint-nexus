// Usage & Interfaces

Execution Paradigms

Integrate OSINT Nexus into automated threat intelligence pipelines via the core asynchronous facade:

python
from osint_nexus.core.agent import OSINTAgent

# Initialize OSINT Agent Facade for target username
agent = OSINTAgent(username="target_user")

# Asynchronously stream platform intel as scans finalize
async for intel in agent.run_scan("target_user"):
    print(f"Found on {intel.platform}: {intel.found}")

# Retrieve aggregated telemetry & confidence reports
report = agent.get_final_report()

Execute target scans directly from modern terminal shells or Termux on Android devices:

Target Reconnaissance Scan:
python -m osint_nexus.cli scan --username target_user
Provider Network & Circuit Breaker Health Check:
