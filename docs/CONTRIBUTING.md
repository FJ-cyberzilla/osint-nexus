# Contributing to OSINT-Nexus

We welcome contributions! Please follow these guidelines:

## Development Workflow
- **Branching:** Use descriptive branch names (e.g., `feature/my-feature`, `fix/my-fix`).
- **Pull Requests:** Ensure all tests pass and code strictly adheres to `mypy --strict`.
- **Types:** Follow the `TYPE_RESOLUTION_PLAN.md` for refactoring.
- **Tests:** Add industrial-level unit tests for new features using `pytest`.

## Getting Started
1. Fork the repository.
2. Create a branch (`git checkout -b feature/my-feature`).
3. Make your changes.
4. Run tests: `pytest`.
5. Push your branch and open a PR.
